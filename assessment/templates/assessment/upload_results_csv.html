CSV Format

Header row required, exactly these 4 columns:

student_id,subject_code,ca_score,exam_score
SCH-2026-0001,MATH101,32,55
SCH-2026-0002,MATH101,28,49
  • student_id — must match an existing Student ID exactly (e.g. SCH-2026-0001).
  • subject_code — must match an existing Subject code (see Academics > Subjects in /admin/).
  • ca_score — Continuous Assessment, 0–40.
  • exam_score — Examination score, 0–60.
  • A plain Teacher can only upload subjects they are assigned to teach. Senior Teachers, Vice Principals and the Principal can upload for any subject.
